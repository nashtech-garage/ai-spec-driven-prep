# Resources

Optional reading. Check each page for the latest information, because products and course content change over time.

## AI fundamentals

- [3Blue1Brown: neural networks video series](https://www.3blue1brown.com/topics/neural-networks): visual explanations of how neural networks learn.
- [Andrej Karpathy: Intro to Large Language Models (video)](https://www.youtube.com/watch?v=zjkBMFhNj_g): a one-hour overview of how LLMs are trained and used.
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course): an introduction to machine learning concepts.

## AI tools and plans

- [GitHub Copilot plans](https://github.com/features/copilot/plans): compare Free, Student and Pro.
- [Plans for GitHub Copilot (documentation)](https://docs.github.com/en/copilot/get-started/plans): limits and feature details.
- [Google AI subscriptions](https://gemini.google/subscriptions): Google AI Plus and other plans, with availability by country.

## GitHub Copilot

- [GitHub Copilot documentation](https://docs.github.com/en/copilot): what Copilot can do, how to use it and its limits.

## AI engineering and building blocks

- [roadmap.sh: AI Engineer roadmap](https://roadmap.sh/ai-engineer): a community map of topics for building AI products, from LLM basics to evals and agents.
- [Model Context Protocol](https://modelcontextprotocol.io): the official introduction, specification and examples for MCP.
- [AGENTS.md](https://agents.md): a simple, open format for giving coding agents project instructions.
- [Anthropic: Building effective agents](https://www.anthropic.com/engineering/building-effective-agents): when to use simple workflows and when to use agents.
- [Prompt Engineering Guide](https://www.promptingguide.ai): patterns for prompts, RAG and agents, with examples.
- [Hamel Husain: Your AI product needs evals](https://hamel.dev/blog/posts/evals/): why and how to test AI features systematically.
- [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/): common security risks, including prompt injection.
- [Langfuse documentation](https://langfuse.com/docs): an open-source example of tracing and monitoring LLM applications.
- [walkinglabs: learn-harness-engineering](https://github.com/walkinglabs/learn-harness-engineering): a course on building the environment around AI agents, which inspired this guide's structure.
