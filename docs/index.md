## Who this guide is for

This guide is for students who can write basic code and use Git or an AI chat tool. You do not need prior knowledge of machine learning or mobile development.

## What you will be able to do

After reading the guide you should be able to:

- Explain at a basic level what a large language model (LLM) does and why its output can be wrong.
- Tell the difference between a chat assistant and a coding agent.
- Notice when a feature request is missing information, and write a simple acceptance example.
- Follow a demo that uses GitHub Copilot and GitHub Spec Kit, even if you do not remember every command.

## How to use this guide

1. Read sections 1 to 5 in order. They take about 25 minutes.
2. Try the warm-up exercise and answer the self-check questions.
3. Follow the [setup checklist](/06-setup-checklist) if you plan to take part in the hands-on session.
4. Bring one question, or one example where an AI answer was wrong or unclear.

::: tip No AI account needed
You can complete the reading and exercises without an AI account. If you have one, you may try the prompts yourself, but always check the results.
:::
